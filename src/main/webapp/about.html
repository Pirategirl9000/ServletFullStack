Tomcat

This web application is being run by a web server known as Apache Tomcat

Apache Tomcat is an HTTP webserver that works with Jakarta EE Servlets which are running this application

This program is run with Tomcat 11.0.18

Jakarta Servlets

Apache Tomcat relies on Jakarta servlets to handle server requests. A servlet is a Java class that listens for server requests in a web container (Tomcat) and responds to them

Servlets are the backbone of Java web applications and enable the creation of backend APIs which can communicate with the frontend

This program is run with Jakarta EE 11
