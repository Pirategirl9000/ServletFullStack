## Purpose
The purpose of this project is to develop a further understanding of web development by stepping down a level of abstraction
and using the old servlet technology of Java. Without the utility of a framework like Spring this requires I figure out
how to manage the database connections, handle the JSON parsing, configure a templating engine for dynamic web content, and many more things

## Reflection
This project taught me a lot about the world of web development. Having to step down a level of abstraction had me doing a lot of the grunt work that is usually abstracted away.
This project required I read a lot of documentation due to the lack of people discussing Jakarata Servlets. This developed my skills
in reading documentation by quite a bit. After this project, I find it much easier to sit down with documentation and read it.

It is important to highlight my struggle points as well. Styling remains a weak point of mine. Through this project I did improve a little in
my CSS abilities, but it still remains a difficulty of mine.

Additionally, I struggled with implementing the Thymeleaf standard dialect into my project.
While there is a lot of documentation regarding how to use Thymeleaf in Spring there is not much for how to implement it into a Jakarta project.
